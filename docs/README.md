# Documentation

## The concept

**[Maturity model](maturity/README.md)** — seven stages of organizational
understanding of web performance, one document per level. It describes how
organizations come to understand speed at all: what someone at each stage can
say, what they must have to say it, and what each stage hides that eventually
forces them to the next.

This stands on its own. It is not a description of software, and nothing in it
depends on this project existing.

## The calculator

The calculator is one way of showing that progression — a model of the
relationship between speed and business outcomes, with a screen per level that
reveals as much of it as that level has earned.

- **[Data model](data_model.md)** — the parameters, the revenue equation and
  the series derived from them. What the calculator computes, and which terms
  each level holds constant.
- **[User interface](user_interface.md)** — how each level puts that model on
  screen: which controls are open, which are folded away, and which percentiles
  are drawn.
