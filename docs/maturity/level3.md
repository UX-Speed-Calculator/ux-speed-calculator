# Level 3 — How Fast is My Site?

**Maturity:** Start measuring speed, set thresholds

Speed becomes a number with units: 3.4 seconds, the time it takes to do one
important thing. Naming the thing matters as much as the measurement — a
duration is only meaningful when it is attached to a user action rather than a
technical event. The instrument is usually synthetic testing, and the reading
is sorted against thresholds into poor, needs improvement, or good, which is
what finally makes a target expressible. The number arrives as a plain fact
about the site, the way a room is three metres wide: there is no notion yet of
a population standing behind it, nothing statistical about it, no sense that
different people got different answers. Synthetic testing reinforces exactly
that reading, since one test on one device over one network does produce a
single true answer. That is the unresolved problem here — the number is being
read as a property of the site, when what it was actually made from is people.
