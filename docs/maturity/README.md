# The UX Speed Maturity Model

Seven **stages of understanding** an organization passes through on its way to
being able to answer one question honestly:

> What is UX Speed worth to us?

Each level is a legitimate place to stand. Each one is also a simplification
that eventually breaks, and the way it breaks is what promotes you to the next
level.

This is a description of how organizations come to understand web performance.
It stands on its own, independent of any tool.

Each level has two names. The **question** is what someone at that level is
trying to answer. The **maturity state** is where their organization stands.
One level per file:

| Level          | Question it answers              | Maturity state                                       | The number you hold                    |
| -------------- | -------------------------------- | ---------------------------------------------------- | -------------------------------------- |
| [1](level1.md) | What matters to my business?     | Web performance is not understood by business        | Revenue                                |
| [2](level2.md) | Is my site fast or slow?         | UX speed impacts business                            | Two conversion rates                   |
| [3](level3.md) | How fast is my site?             | Start measuring speed, set thresholds                | One duration                           |
| [4](level4.md) | Fast for whom?                   | Numbers represent users; use percentiles             | A duration, at a percentile            |
| [5](level5.md) | Are we getting faster or slower? | Track percentiles over time                          | Several percentiles over time          |
| [6](level6.md) | What do all my users experience? | Understand all your users; visualize distributions   | A distribution                         |
| [7](level7.md) | What is this change worth?       | Compare distributions; correlate to business metrics | A difference between two distributions |
